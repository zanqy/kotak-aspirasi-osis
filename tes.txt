## ARSITEKTUR ANIMASI YANG DIINGINKAN

### 1. Dua Mode Animasi

| Mode | Trigger | Durasi | Karakteristik |
|------|---------|--------|---------------|
| **First Visit (Full Experience)** | `sessionStorage.getItem('hasVisited') === null` | 2.5–3 detik | Semua efek hidup (typewriter, garis ditarik, stagger, spring) |
| **Navigation (Quick Transition)** | `sessionStorage.hasVisited = 'true'` | 0.4–0.6 detik | Hanya fade + slide horizontal, tanpa efek berat |

**State Management:**
- Gunakan `sessionStorage` dengan key `'hasVisited'`
- Set `'true'` setelah animasi first visit selesai
- Pada hard refresh, tetap full experience

### 2. First Visit — Entrance Animation (Landing Page)

**Deskripsi:** Halaman utama (`/`) saat pertama kali dibuka. Semua animasi berjalan **parallel dengan stagger**, bukan sequential.

#### Timeline Lengkap (Total 2.8 detik)

| Waktu Mulai | Elemen | Efek | Durasi | Easing | Detail Teknis |
|-------------|--------|------|--------|--------|---------------|
| **0.0s** | Background & Hero Judul | Fade in (opacity 0→1) | 600ms | `ease-out` | Background halaman muncul, teks judul besar muncul |
| **0.3s** | Hero Heading (Typewriter) | Typewriter effect | 1.7s | `linear` | Huruf per huruf, cursor berkedip, setelah selesai cursor hilang |
| **0.5s** | Garis Form "Ditarik" | `scaleX(0 → 1)` | 1.3s | `ease-out` | Garis horizontal memanjang dari kiri ke kanan, `transform-origin: left`, warna `#c8dde8` |
| **0.7s** | Container Form (Card) | `opacity 0→1` + `translateY(20px→0)` | 1.2s | `ease-out` | Muncul di atas garis, background putih dengan shadow |
| **1.0s** | Dropdown Kategori | `translateY(15px→0)` + `opacity 0→1` | 0.8s | `ease-out` | Muncul dari bawah |
| **1.2s** | Textarea | `translateY(15px→0)` + `opacity 0→1` | 0.8s | `ease-out` | Muncul dari bawah |
| **1.4s** | Input Email | `translateY(15px→0)` + `opacity 0→1` | 0.8s | `ease-out` | Muncul dari bawah |
| **1.6s** | Tombol Kirim | `scale(0.5 → 1.05 → 1)` + `opacity 0→1` | 0.9s | Spring `cubic-bezier(0.34, 1.56, 0.64, 1)` | Membesar dengan efek pegas, shadow muncul bersamaan |

**Catatan Penting:**
- Semua delay bersifat **relative terhadap start time masing-masing**, bukan menunggu sebelumnya selesai. Inilah yang membuat terasa "bersamaan tapi tidak bersamaan".
- Typewriter hanya untuk **hero heading** (bukan seluruh teks).
- Garis "ditarik" adalah elemen dekoratif di atas form — bisa berupa `div` dengan `height: 2px` dan `background: #c8dde8` yang di-`scaleX`.

### 3. Navigation — Horizontal Slide Transition

**Deskripsi:** Setiap pindah halaman di dalam dashboard atau dari landing ke halaman lain (kecuali first visit), gunakan **slide horizontal** dengan durasi cepat.

**Implementasi:**
- Gunakan `AnimatePresence` dari Framer Motion (atau CSS transition dengan `transform: translateX`)
- **Arah slide:** bergantung arah navigasi:
  - Ke halaman **lebih dalam** (misal `/dashboard` → `/dashboard/aspirasi`): slide **kiri** (halaman baru masuk dari kanan)
  - Ke halaman **lebih tinggi** (back, misal `/dashboard/aspirasi/123` → `/dashboard/aspirasi`): slide **kanan** (halaman baru masuk dari kiri)
- **Durasi:** 400ms
- **Easing:** `ease-in-out`
- **Layer:** Halaman baru menutupi halaman lama (seperti native app)

**Spesifikasi Teknis:**
- Gunakan `motion.div` dengan `initial`, `animate`, `exit`
- Untuk menentukan arah, gunakan `usePathname()` dan bandingkan depth URL, atau simpan history stack di context.

### Spesifikasi Teknis Detail

#### A. `useFirstVisit` Hook
```typescript
// hooks/useFirstVisit.ts
export function useFirstVisit(key: string = 'hasVisited'): boolean {
  const [isFirst, setIsFirst] = useState(true);
  useEffect(() => {
    if (typeof window === 'undefined') return;
    const visited = sessionStorage.getItem(key);
    if (visited === 'true') {
      setIsFirst(false);
    } else {
      sessionStorage.setItem(key, 'true');
      setIsFirst(true);
    }
  }, [key]);
  return isFirst;
}
```

#### E. `PageTransition` (Horizontal Slide)
```tsx
// components/animations/PageTransition.tsx
import { motion, AnimatePresence } from 'framer-motion';

export function PageTransition({ children, direction = 'left' }) {
  const isLeft = direction === 'left';
  return (
    <AnimatePresence mode="wait">
      <motion.div
        key={usePathname()}
        initial={{ x: isLeft ? 300 : -300, opacity: 0 }}
        animate={{ x: 0, opacity: 1 }}
        exit={{ x: isLeft ? -300 : 300, opacity: 0 }}
        transition={{ duration: 0.4, ease: 'easeInOut' }}
      >
        {children}
      </motion.div>
    </AnimatePresence>
  );
}
```
**Penentuan arah:** bandingkan depth path dengan `pathname.split('/').length`. Jika lebih dalam → left, jika kembali → right.

#### F. `useCountUp` Hook
```typescript
// hooks/useCountUp.ts
export function useCountUp(target: number, duration: number = 800) {
  const [count, setCount] = useState(0);
  useEffect(() => {
    const start = performance.now();
    const animate = (now: number) => {
      const progress = Math.min((now - start) / duration, 1);
      setCount(Math.floor(progress * target));
      if (progress < 1) requestAnimationFrame(animate);
    };
    requestAnimationFrame(animate);
  }, [target, duration]);
  return count;
}
```

#### G. `prefers-reduced-motion` Handling
```typescript
// hooks/usePrefersReducedMotion.ts
export function usePrefersReducedMotion() {
  const [prefersReduced, setPrefersReduced] = useState(false);
  useEffect(() => {
    const mediaQuery = window.matchMedia('(prefers-reduced-motion: reduce)');
    setPrefersReduced(mediaQuery.matches);
    const handler = (e: MediaQueryListEvent) => setPrefersReduced(e.matches);
    mediaQuery.addEventListener('change', handler);
    return () => mediaQuery.removeEventListener('change', handler);
  }, []);
  return prefersReduced;
}
```
**Implementasi:** Di setiap komponen animasi, jika `prefersReduced === true`, langsung render tanpa animation (atau dengan duration 0).

### Animasi Realtime (Pesan Baru di Chat)

**Skenario:** Saat ada pesan baru masuk via Supabase Realtime, bubble baru muncul dengan animasi.

**Implementasi:**
1. Subscription di `useEffect` di halaman detail.
2. Saat ada pesan baru, tambahkan ke state `messages`.
3. Untuk bubble baru, gunakan:
```tsx
<motion.div
  initial={{ opacity: 0, y: 20 }}
  animate={{ opacity: 1, y: 0 }}
  transition={{ duration: 0.3, ease: 'easeOut' }}
>
  <ChatBubble ... />
</motion.div>
```
4. Setelah render, scroll ke bawah:
```tsx
useEffect(() => {
  const el = document.getElementById('chat-container');
  if (el) el.scrollTo({ top: el.scrollHeight, behavior: 'smooth' });
}, [messages]);
```

### Performance Optimization

- **Semua animasi menggunakan `transform` dan `opacity`** (tidak memicu layout/reflow).
- **Gunakan `will-change: transform, opacity`** pada elemen yang dianimasi (tapi hati-hati overuse).
- **Batch DOM updates** untuk stagger (Framer Motion handle ini otomatis).
- **Lazy load Framer Motion?** Tidak perlu, karena sudah digunakan di banyak halaman.
- **Gunakan `useMemo`/`useCallback`** untuk variants yang tidak berubah.
